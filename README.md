# Signature by Lilian — Website Brief

## Brand Overview

**Signature by Lilian** is a premium beauty, skincare, and wellness brand built around two connected offerings:

- **Signature by Lilian Skincare** — a skincare and beauty product line.

- **Signature by Lilian Oasis** — a luxury spa and wellness experience.

The website should present both as part of the same parent brand while giving each division its own visual identity.

The overall experience should feel **premium, feminine, elegant, sophisticated, warm, and luxurious** without becoming overly flashy or generic.

---

# Brand Identity

## Parent Brand

**Signature by Lilian**

The brand logo features a stylized peacock combined with the word "Signature".

The peacock represents:

- Beauty

- Elegance

- Transformation

- Luxury

- Confidence

- Uniqueness

The logo should be treated as a major brand asset and should NOT be recreated with ordinary text or substituted with a generic icon.

Use the provided official logo assets throughout the website.

# Brand Divisions

## 1. Signature by Lilian Skincare

### Purpose

Signature by Lilian Skincare is the product side of the business, focused on skincare and personal beauty.

The website should allow customers to:

- Discover skincare products

- Browse products

- View detailed product information

- Understand product benefits

- Add products to cart

- Purchase products

- Read reviews

- Learn about skincare and proper routines

### Visual Identity

The skincare division uses a:

**Purple / Magenta / Pink** colour direction.

Primary visual feeling:

- Feminine

- Vibrant

- Elegant

- Beautiful

- Confident

- Modern

- Luxurious

### Suggested Colour Direction

Use the actual skincare logo as the primary colour reference.

Core colours can include:

- Deep Purple

- Royal Purple

- Magenta

- Fuchsia / Pink accents

- Soft blush/pink

- White

- Very light neutral backgrounds

- Dark charcoal for readable text

Do NOT make the entire site aggressively purple.

Purple/magenta should be used strategically for:

- Buttons

- Links

- Highlights

- Product accents

- Decorative elements

- Section headings

- Hover states

- Brand moments

White and soft neutral space should keep the interface premium and clean.

---

# 2. Signature by Lilian Oasis

### Purpose

Signature by Lilian Oasis is the spa and wellness side of the brand.

It should feel like an escape from everyday life — calm, luxurious, intimate, and relaxing.

The website should allow visitors to:

- Explore spa services

- Learn about treatments

- View treatment details

- See pricing where available

- Book appointments

- Choose preferred dates/times

- Contact the spa

- Discover the Oasis experience

### Visual Identity

The Oasis division uses a:

**Gold / Champagne / Warm Luxury** colour direction.

The provided Oasis logo should be the main visual reference.

Primary visual feeling:

- Luxury

- Calm

- Sophistication

- Warmth

- Exclusivity

- Relaxation

- Premium hospitality

### Suggested Colour Direction

Use the Oasis logo as the exact visual reference.

Core colours can include:

- Rich Gold

- Champagne Gold

- Warm Metallic Gold

- Cream

- Ivory

- Warm Beige

- White

- Deep charcoal / near-black for contrast

Gold should feel refined rather than yellow.

Avoid bright, cheap-looking yellow.

# Design System

## Overall Style

The website should feel:

**Luxury + Modern + Feminine + Editorial + Clean**

Avoid:

- Generic beauty templates

- Excessive gradients

- Excessive rounded cards

- Cartoonish icons

- Cheap-looking gold

- Overuse of purple

- Clutter

- Excessive animations

- Generic stock-photo aesthetics

The design should rely heavily on:

- Beautiful photography

- Typography

- White space

- Strong layouts

- Subtle animations

- Elegant transitions

- High-quality product imagery

- Premium editorial composition

---

# Typography

Use an elegant serif font for major headings paired with a clean modern sans-serif for body text.

Suggested direction:

**Headings:**

- Playfair Display

- Cormorant Garamond

- DM Serif Display

- Or another sophisticated editorial serif

**Body/UI:**

- Inter

- Manrope

- DM Sans

- Montserrat

Typography should create a premium editorial feeling without sacrificing readability.

---

# Animation

Animations should be subtle and intentional.

Use:

- Fade-in

- Gentle slide-up

- Image reveals

- Smooth hover transitions

- Soft parallax where appropriate

- Elegant page transitions

Do NOT make everything move.

The website should feel expensive, not like a UI animation demonstration.

---

# Important Brand Rule

The two divisions must be visually connected but clearly distinguishable.

### Skincare

**Purple / Magenta**

Represents:

- Beauty

- Energy

- Femininity

- Confidence

- Skincare

### Oasis

**Gold / Champagne**

Represents:

- Luxury

- Relaxation

- Wellness

- Exclusivity

- Spa experience

The parent brand remains **Signature by Lilian**.

Do not create two completely unrelated websites.

They should feel like two experiences belonging to the same luxury brand.

---

# Responsive Design

The website must be fully responsive.

Prioritize:

- Mobile

- Tablet

- Desktop

- Large desktop displays

The mobile experience should not simply be a compressed desktop design.

Navigation, product browsing, booking and CTAs should all be optimized for touch.

---

# Overall Goal

The website should make a visitor immediately understand:

> **Signature by Lilian is a premium beauty and wellness brand offering both exceptional skincare products and luxurious spa experiences.**

A visitor should be able to arrive on the homepage and quickly choose between:

**SHOP SKINCARE**

or

**EXPERIENCE OASIS**

The final design should feel like a real premium beauty/wellness brand — not a generic ecommerce template.
